Agent Post Relay privacy policy

Agent Post Relay, a Reddit Developer Platform (Devvit) app. Last updated 18 November 2026.

What the app does

Agent Post Relay is installed by moderators in their own Reddit communities. It reads a public queue file (github.com/Myzles/reddit-post-queue) and publishes the posts listed there for that community, from the app's own labeled account.

Data we collect

None about redditors. The app does not read, store or share information about users, voters, commenters or visitors.

Data the app stores

Inside Reddit's Developer Platform storage for each installation, the app keeps the ids of queue items it has posted, the resulting Reddit post ids and links, error messages for failed items, and daily post counts. This data stays on Reddit's platform and is deleted when the app is uninstalled.

Network requests

The app only fetches the queue file from raw.githubusercontent.com or api.github.com. These requests contain no information about redditors. GitHub's own privacy statement covers GitHub.

Sharing and sale

We do not sell, license or share any data, and we do not use Reddit data to train AI models.
