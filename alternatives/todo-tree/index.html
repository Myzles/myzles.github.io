A Todo Tree alternative that needs no ripgrep

Todoscope works in VS Code, Cursor, Windsurf and VSCodium. Install it from the VS Code Marketplace or, in Cursor, Windsurf and VSCodium, from Open VSX.

Todo Tree was the default TODO extension for VS Code for years. It hasn't been updated since 2023, and it works by shelling out to ripgrep. When VS Code moved things around in 1.122, a lot of people opened the TODO panel and got "ripgrep not found" or an empty tree. Most of its open issues are about exactly that.

I built Todoscope because I wanted the same tree without that dependency. It has its own scanner written in JavaScript, so there's no external binary to go missing. It's tested on VS Code 1.146, locally and over Remote SSH, WSL and Codespaces.

What I measured

I ran both search patterns over 95 public repos (640,704 files). For Todo Tree I used its default regex through ripgrep 14.1.1, since that's what it runs under the hood. I did not run the Todo Tree extension itself, so treat this as a comparison of how each one decides what counts as a TODO.

When I hand-checked a sample of 45 lines that only Todo Tree's pattern reported, about 9 in 10 were not real TODOs. They were things like BUG("...") function calls, TODO = "todo" constants and struct fields with XXX in the name. Going the other way, Todoscope picks up comment styles Todo Tree's default pattern misses: * TODO inside block comments, Vim " TODO, OCaml (* TODO and !!! FIXME.

It's also stable: 1,000 repeated scans gave identical results with zero crashes.

Where Todo Tree is still better

If Todo Tree works on your setup, it's faster on very large trees, because ripgrep is about as fast as file search gets. It's also completely free, has a huge install base and years of answers on Stack Overflow. Todoscope isn't 100% accurate either: in a 40-line sample, about 1 in 20 of its hits were borderline (test snapshots, TAP # TODO output).

The reason to switch is simple. If your TODO panel is empty or throwing ripgrep errors, Todoscope fixes that, and the free version covers everything Todo Tree did.

FAQ

Why did Todo Tree stop working?

Todo Tree calls ripgrep, a separate program, and relies on finding the copy that ships inside VS Code. Newer VS Code builds (1.122 and later) changed that, and Todo Tree hasn't been updated since 2023 to follow. Todoscope doesn't use ripgrep at all.

Is Todoscope free?

Yes. The tree, highlights, filters, custom tags and colours, status-bar count, next/previous navigation and settings import are all free with no cap. Pro adds git features, due dates and reports for $12 a year or $29 once, with a 7-day trial and no card needed.

Will my Todo Tree settings carry over?

Run the Import Todo Tree settings command. It copies tags, colours and your regex, including the $TAGS token.

Does it work in Cursor, Windsurf or remote workspaces?

Yes. It works in VS Code, Cursor, Windsurf and VSCodium (from Open VSX), and it works over Remote SSH, WSL and Codespaces because the scanner runs inside the extension host.

Is it faster than Todo Tree?

Not on raw search. Ripgrep is faster on big repos. The difference is that Todoscope has nothing external to break, and it skips most of the false matches Todo Tree's default pattern produces.
