How to find emails from a list of websites

You have a spreadsheet with a column of websites (a lead list, a directory export, an event attendee list) and you want an email for each one. Doing it by hand takes two or three minutes a site. Here's the whole process, so you can do it yourself in a sheet or a short script, and what to watch for at every step.

Looking at a single website? Start with How to find email addresses on a website, which covers hidden and obfuscated addresses in detail.

1. Clean the list first

Most of the mess in a list-of-websites job comes from the list itself. Before anything else, make a domain column next to your URLs:

  • Lowercase everything and strip https://, http:// and www.
  • Cut everything after the first /, so acme.com/about?utm_source=x becomes acme.com
  • Remove duplicates on the domain column (in Sheets: Data, Data cleanup, Remove duplicates)
  • Flag rows that aren't company sites: Facebook pages, Linktree, Yelp and Google Maps links. They need a different approach, or a search for the real site.

A Google Sheets formula that does the first two in one go, with the URL in A2:

=LOWER(REGEXEXTRACT(REGEXREPLACE(A2,"^https?://(www\.)?",""),"^[^/?#]+"))

2. Decide which pages to check

The homepage alone misses a lot. For each domain, these are the pages worth fetching, roughly in order of how often they have an email:

PageWhy
Homepage (footer)Many small businesses put the address in the footer of every page.
/contact, /contact-usThe obvious one, though often just a form.
/about, /teamSmall firms list each person with their own address.
/impressum, /imprintRequired for German and Austrian businesses, almost always has an email.
/privacyNames a contact for data requests.

Better than guessing paths: read the homepage's links and follow the ones whose text or URL contains contact, about, team, imprint or kontakt. That catches sites that use /get-in-touch or a different language.

3. Pull the emails out of each page

On each page, look in two places in the HTML: mailto: links, and plain text matching an email pattern. Then throw away the junk you'll always get:

  • Image names that look like emails: logo@2x.png
  • Placeholders: you@example.com, email@domain.com, name@yourcompany.com
  • Addresses on tracking, font and web-agency domains (sentry, wixpress, the designer's own credit in the footer)
  • Obfuscated ones (info [at] acme [dot] com, Cloudflare's [email protected]) need decoding, as covered in the single-site guide

If a site is built with JavaScript (lots of Wix and some Squarespace sites), the raw HTML may have no email at all and you need a real browser to see it. This is where most do-it-yourself scripts quietly miss results.

4. Dedupe and pick one best email per company

You'll often get three to ten addresses per site. For a lead list you usually want one row per company with the best address first. A simple order that works:

  1. Generic inboxes on the company's own domain: info@, hello@, sales@, office@
  2. Named people on the company domain: rob@acme.com
  3. Free mailboxes (Gmail, Outlook), which many very small businesses really do use as their main address
  4. Everything else (jobs@, press@, privacy@) last

Keep the rest in an "all emails" column separated by semicolons, so each company stays on one row.

5. Check each domain can receive mail

Before you import anything into a cold email tool, check the domain has mail servers. On Windows, macOS or Linux:

nslookup -type=mx acme.com

No MX records means mail to that domain will bounce, so drop it. Having MX records doesn't prove the particular mailbox exists, and some servers accept everything and bounce later, so treat this as a filter, not verification.

6. Doing it in Google Sheets or Python

Google Sheets

For a short list you can fetch a page and pull emails with Apps Script (Extensions, Apps Script). This custom function returns the emails on one page:

function EMAILS(url) {
  var html = UrlFetchApp.fetch(url, {muteHttpExceptions: true}).getContentText();
  var found = html.match(/[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}/gi) || [];
  var clean = found.filter(function (e) { return !/\.(png|jpe?g|gif|svg|webp)$/i.test(e); });
  return Array.from(new Set(clean.map(function (e) { return e.toLowerCase(); }))).join("; ");
}

Use it as =EMAILS("https://"&B2&"/contact"). Limits: it only reads the one page you point it at, it can't see JavaScript-rendered addresses, and Apps Script has daily fetch quotas, so it suits dozens of sites, not thousands.

Python

A minimal version with requests: fetch the homepage, follow contact-like links, collect emails, filter junk.

import re, requests
from urllib.parse import urljoin
EMAIL = re.compile(r"[\w.+-]+@[\w-]+\.[\w.-]+")
KEYS = ("contact", "about", "team", "imprint", "impressum", "kontakt")

def emails_for(domain):
    base = "https://" + domain
    try:
        home = requests.get(base, timeout=15).text
    except requests.RequestException:
        return []
    links = re.findall(r'href="([^"]+)"', home)
    pages = [base] + [urljoin(base, l) for l in links if any(k in l.lower() for k in KEYS)][:6]
    found = set()
    for url in pages:
        try:
            found |= set(EMAIL.findall(requests.get(url, timeout=15).text))
        except requests.RequestException:
            pass
    return sorted(e.lower() for e in found
                  if not e.lower().endswith((".png", ".jpg", ".svg", ".webp")))

Run it over your domain column and write the results back to CSV. To make it production-grade you'd still need to decode obfuscated addresses, render JavaScript sites in a headless browser, rank the emails, run the MX check, and handle timeouts and sites that block scripts.

FAQ

How do I extract emails from a list of URLs?

Clean the list to one domain per row, fetch each site's homepage and contact, about, team and imprint pages, search the HTML for mailto: links and email patterns, drop junk, then keep one best email per domain.

Can Google Sheets pull emails from websites?

Partly. IMPORTXML or a small Apps Script can fetch a page and match email patterns, but it only sees the HTML of one page, misses addresses added by JavaScript, and hits fetch limits on long lists.

How do I remove duplicate websites from a list?

Reduce every URL to its bare domain (lowercase, no https://, no www., no path) and remove duplicates on that column. Two links to the same company then collapse to one row.

Does an MX record mean the email is valid?

No. It means the domain can receive mail. The specific mailbox can still bounce, and some servers accept everything and bounce later.

How many websites will have an email?

It depends on the list. Many small businesses only publish a contact form, so plan for some rows with a phone or form but no email.
