Free n8n and Make templates

Ready-made automations for two common sales jobs: getting contact details for a list of companies, and spotting which target accounts are hiring. Both run on Apify, so you pay only for what each run finds (Apify's free plan includes monthly credit).

Before you start: your Apify token

  1. Sign in at console.apify.com (free account).
  2. Open Settings › API & Integrations and copy your personal API token.
  3. In n8n, create a Header Auth credential: name Authorization, value Bearer YOUR_TOKEN. In Make, connect the Apify app with the same token.

1. Find emails and phones for a list of websites

Paste websites (or a Google Maps lead list) and get each company's best email, phone, social profiles, address and contact page, using Website Contact Finder. You pay $4 per 1,000 websites where contacts are found. Websites with nothing found are free.

n8n

Download the n8n workflow

In n8n, choose Import from file (or paste the file's contents onto the canvas). Pick your Header Auth credential in the Find contacts node and edit the website list in Websites to check. The workflow keeps only rows where contacts were found and trims them to the useful columns. Add a Google Sheets, HubSpot or Airtable node at the end to save them.

Make

  1. Add Apify › Run an Actor. Actor: myzles/website-contact-finder. Run synchronously: Yes. Input JSON: {"websites": ["acmeplumbing.com", "bluebottlecoffee.com"]} (or map a column from a Google Sheets "Search Rows" module).
  2. Add Apify › Get Dataset Items and map the dataset ID from step 1.
  3. Add a filter: status equals Contacts found.
  4. Add Google Sheets › Add a Row and map companyName, website, primaryEmail, primaryPhone, linkedin and contactPage.

2. Weekly hiring signals for your target accounts

Every Monday, check your target accounts' career pages and get a short note for each company that is hiring hard: open roles, new roles since last week, which teams are growing and a signal score, using Company Hiring Signals.

n8n

Download the n8n workflow

Import it, pick your Header Auth credential in Get hiring signals and put your accounts in Target accounts (names or websites). Strong signals only keeps companies with a score of 50 or more. Connect the Summary line node to Slack, email or your CRM to get the message each week. Because it asks for new roles only, each week shows what changed.

Make

  1. Start with a Schedule set to weekly.
  2. Add Apify › Run an Actor. Actor: myzles/company-hiring-signals. Run synchronously: Yes. Input JSON: {"companies": ["Stripe", "ramp.com"], "output": "companies", "onlyNew": true}.
  3. Add Apify › Get Dataset Items with the dataset ID from step 2.
  4. Add a filter: signalScore greater than or equal to 50.
  5. Add Slack › Create a Message (or Gmail) with {{company}}: score {{signalScore}}, {{openRoles}} open roles. {{buyingSignalsText}}.

Other tools these work with

The same pattern (Run an Actor, then Get Dataset Items) works with Decision Maker Finder, Telegram Channel Scraper and Google Ads Transparency Scraper. Change the actor name and the input.
